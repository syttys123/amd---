## 事实口径

- 当前候选包为 `1.0.22-native`，默认只读。
- 唯一完整实机证据：MECHREVO WUJIE15 PRO / AMD Ryzen 7 8845HS。
- 受控当前值策略门禁：AC `10/10/10 W` 同值写回/回读；策略随后禁用、
  worker 正常关闭。
- 当前本地状态：预设 `10 / 25 / 45 W`（可编辑），上限 `45 W`，自动策略关闭，
  当前用户选择 AC `10/10/10 W`；`10 W` 是夜间手动档。
- 包内提供 elevated WinRing0 安装与安全卸载脚本；更新驱动前会等待旧服务停止。
- 已验证打包版托盘、任务栏图标、单实例、模式同步、诊断导出、简洁/高级模式
  短屏滚动和 1366x768/200% 工作区夹具。
- worker 卡死替换：34.6 秒完成替换，22 次窗口响应采样 0 失败，策略恢复。
- 当前没有第二台 AMD 设备；其他世代仍是实验性配置。
- Windows 无法区分 USB-C 充电宝和墙插，两者统一显示为“电源”。
- 不声明支持所有 AMD 笔记本，不建议为运行开发版关闭系统安全防护。
- 宣传片草稿 107.7 秒，SAPI 中文配音 + 原创合成配乐，尚未上传。

## GitHub Release 草稿

标题：

```text
1.0.22-native — AMD Mobile Power 原生稳定本地候选
```

正文：

````markdown
## 原生候选

AMD Mobile Power 将 RyzenAdj 封装为原生 Rust GUI + C++ worker，默认只读。
本候选面向 AMD 轻薄本，目标是让实时功耗、固件上限、目标设置和兼容性诊断
在一个窗口中可见。

## 本版重点

- 600x360 紧凑简洁模式：实时功耗、可编辑目标、三档预设、四列遥测。
- 高级模式按显示器工作区打开，矮屏/高缩放时整页滚动，底栏不再被任务栏遮挡；
  简洁模式在极矮工作区也可纵向滚动。
- 目标与预设草稿在每秒刷新和模式切换之间保留；按钮只响应真实点击。
- 悬停、手形光标、键盘焦点环、原生 tooltip 与高对比度主题。

## 已验证

- Ryzen 7 8845HS / Hawk Point 只读能力与遥测。
- AC `10/10/10 W` 当前值写回、回读与策略禁用。
- 44/44 Rust 测试、7/7 探针测试、C++ 策略测试、Clippy、19 项包内 SHA256。
- 同提交逐字节可复现：GUI `288f86de`、worker `67af1d41`、探针 `9750418f`、
  ZIP `500224c7`。
- worker 卡死替换：34.6 秒，22 次响应采样 0 失败，策略恢复。
- 逻辑 100/125/150% 与 1366x768/200% 工作区夹具、托盘、任务栏图标、单实例唤醒。
- 高对比度、本地化、诊断脱敏和兼容性报告导入。

## 安全边界

这是单设备验证的内部候选，不是“全 AMD 通用版”。硬件写入必须显式解锁，
写入后必须回读；不要关闭 Windows 安全防护来运行 WinRing0。不同 AMD
世代、BIOS 和 EC 需要独立证据。

## 兼容性反馈

请从解压后的包运行 `collect-native-diagnostics.ps1`，检查脱敏 JSON 后提交
Issue。收集器只读、不上传、不启用功耗写入。

## 下载

- 原生预览 ZIP。
- 同名 `.sha256` 校验文件。
- 当前只有单台 8845HS 实机证据，其他设备请先提交只读诊断。
````
