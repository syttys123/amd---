## AMD Mobile Power 1.0.30 原生预览候选

AMD Mobile Power 把 RyzenAdj 封装成 Rust 原生 GUI + C++ worker。界面和硬件
访问分开，默认只读，写入前需要阅读免责声明和操作须知并勾选确认。

### 本版重点

- 状态文件现在容忍 UTF-8 BOM：用记事本或 Windows PowerShell 5.1 保存过的
  `rust-ui-state.json` 不会再被当成损坏，预设、策略和写入解锁状态不会
  静默回退到默认值。
- 保留 1.0.29 的包内说明修正：应用内锁/托盘“写入解锁…”、`10 / 25 / 45 W`
  默认预设、电池/外接自动策略，以及打包时的 README 内容检查。
- 保留托盘解锁、持久化写权限、worker 重启后自动重发策略、双缓冲绘制、
  滚动收敛、小屏整页滚动和托盘/单实例恢复。

### 已验证

- 25 项库测试 + 23 项主程序测试、7 项探针测试、C++ 策略测试。
- Clippy `-D warnings`、包内 SHA256、逐字节可复现构建。
- 100/125/150% DPI、1366x768/200% 工作区、最大化滚动。
- 关闭到托盘、托盘恢复、单实例唤醒、显式退出。
- worker 卡死自动替换，窗口保持响应，策略恢复。
- Ryzen 7 8845HS 电池同值策略回读 `8/8/8 W`。
- 托管 Windows CI 全步骤通过。

### 安全边界

这是单设备验证的预览候选，不是“全 AMD 通用版”。硬件写入必须显式解锁，
写入后必须回读。不同 AMD 世代、BIOS 和 EC 需要独立证据。不要关闭 Windows
安全防护来运行开发版。
